- Input must be a **VHDL entity**. A verified working shape: `entity demo is port (clk : in std_logic; q : out std_logic_vector(7 downto 0)); end entity;`.
- **Verilog/SystemVerilog did not work**: every `module ... endmodule` probe failed with `ValueError: max() iterable argument is empty`, and a `module` without `endmodule` returned HTTP 200 with an empty body. Non-HDL input (`digraph { a -> b }`) also returns an EMPTY 200. An empty body means nothing rendered; do not treat it as success.
- Other silent-empty traps: closing with `end;` or `end entity demo;` (use `end entity;` or `end demo;`), a missing `;` after the final `end`, and a trailing `;` before the `)` closing the port list. Each returned an empty 200.
- Ascending ranges break the renderer: `std_logic_vector(0 to 7)` fails with `g-markup-error-quark ... "/" is not a valid character following the close element name "spa<"`. Use `(7 downto 0)`. Port mode `buffer` fails (`AssertionError`); use `in`, `out`, `inout`.
- Working: `generic (WIDTH : integer := 8);` plus `std_logic_vector(WIDTH-1 downto 0)`, comma-sharing names `a, b : in std_logic;`, upper-case keywords, `--` comments, several entities in one file, types `unsigned`, `boolean`, `bit`.
